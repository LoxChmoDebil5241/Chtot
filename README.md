# К-47: Нормы расхода плоти

Пошаговая тактическая игра на гексах по мотивам книги «К-47. Нормы расхода плоти. Цикл 48.»
Визуально и механически вдохновлена *War of Folvos*: вид сверху, гексовая сетка, панель юнита внизу,
цели операции сверху. Сеттинг — ледяная планета Ол-12-П (−201 °C), клоны класса «Актив» корпорации
«Vitezstvi», штреки под 191 километром льда, фауна подлёдных полостей и «нормы расхода плоти».

## Как запустить

Сборка не нужна — это чистый HTML/CSS/JS без зависимостей.

* Откройте `index.html` в браузере (Chrome, Firefox, Edge, Safari), **или**
* поднимите любой статический сервер в корне репозитория, например `npx serve .` и откройте адрес в браузере.

Параметры адреса: `?skip` — без интро, `?m=5` — сразу брифинг операции 5.

## Что внутри

* **Интро** — процедурный ролик: звезда С-1, планета «на боку» (наклон оси 82°), капсульная, «Активация завершена».
* **Меню** — продолжить, новая кампания, выбор операции, досье, настройки, повтор интро.
* **Кампания из 10 операций** по сюжету книги:
  1. Вторжение — налёт на «Горн-12» (Кристиан ещё человек).
  2. Глубина — прорыв по логистическому штреку, блокпост и «Панцирь».
  3. Щит — эвакуация учёных под огнём.
  4. Айсберг-3 — оборона логистической базы, мосты через трещину, челноки СНК.
  5. Брак — белые глаза и захват ретранслятора у поста «Мрахна».
  6. Шипение — гнездо фильтраторов, нематоды во льду, кислород на исходе.
  7. Слепота — плазменные штурмовики и газовые карсты.
  8. Коктейль — выжить в карстовой полости без регенерации.
  9. Осознание — серверная ОПЗ и гражданские.
  10. Цикл 47 — финальная оборона «Горна-12», акт передачи нейропрофиля NanoTrasen, эпилог.
* Между операциями — сюжетные интерлюдии (Буклет, Повар, Санитар, Техник, Смотритель, Оскал, Наблюдатель,
  Рациональность) и **плакальщики** — постоянные бонусы кампании.

## Механики

* **Норма расхода плоти** — сколько регенераций корпорация готова оплатить. Погибший клон возвращается
  через 1–2 хода на точку высадки с тем же рангом (нейропрофиль хранит рефлексы). Перерасход — провал.
* **Тела и ДНК** — если вражеский пехотинец зайдёт на тело актива, ДНК утрачена (+1 к расходу).
  Санитары (труповозка) забирают тела и возвращают норму.
* **Кислород** — в штреках счётчик ходов означает запас баллонов.
* **Туман войны, зоны контроля, засады**; затаившиеся нематоды видны только вплотную или геосканером.
* **Перегрузка** — каждая следующая атака по той же цели за ход сильнее на 15% («Панцирь» не пробить — только перегрузить).
* **Мороз и оружие** — лазеры ОПЗ теряют мощность каждый ход, плазме нужен прогрев ствола.
* **Газ** — газовые карсты и каверны взрываются от выстрела, паяльной лампы или плазмы.
* **Стимуляторы** — эфедрин, дизоксиэфедрин, гиперзин, аранепс, импедризин, ноктюрин. Три разных за ход —
  «коктейль»: двойная сила и остановка сердца через ход.
* **Бур** прорезает ледяную толщу, **снайперы и пулемётчики** не стреляют после движения,
  **пулемёт** подавляет цель.
* Три уровня сложности, автосохранение каждый ход, досье с брошюрами и характеристиками юнитов.

## Управление

| Действие | Мышь / тач | Клавиатура |
|---|---|---|
| Выбрать юнит, двигаться, атаковать | ЛКМ / тап (на тач — второй тап по цели = огонь) | Tab — следующий юнит |
| Отмена выбора | ПКМ | Esc |
| Обзор карты | перетаскивание, миникарта | WASD / стрелки |
| Масштаб | колесо / щипок | + / − |
| Конец хода | зелёная кнопка | Пробел / Enter |
| Отменить перемещение | «Отмена» | U |
| Стимуляторы, пополнение, скан, бурить, поджечь | кнопки панели | X, R, C, B, F |
| Сетка вкл/выкл | — | G |

## Структура

```
index.html        точка входа
css/style.css     интерфейс
js/core.js        утилиты, шум, гекс-геометрия, куча для поиска пути
js/data.js        местность, строения, юниты, фракции, стимуляторы, досье
js/missions.js    генератор карт, 10 операций, сюжетные тексты
js/game.js        правила: движение, бой, регенерация, цели, сохранение
js/ai.js          ИИ противника, фауны и гражданских
js/sprites.js     процедурные спрайты и портреты
js/render.js      запекание карты, освещение, туман, частицы, камера
js/audio.js       процедурный звук (WebAudio)
js/intro.js       интро и фон меню
js/ui.js          экраны, HUD, ввод, диалоги, итоги
tools/            headless-симуляция кампании и скриншоты (Node + Playwright)
```

Проверка логики без браузера: `node tools/sim.js 5` — бот проходит все операции по 5 раз и печатает итоги.
